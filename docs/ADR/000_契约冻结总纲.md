## 1. 技能命名规范（统一 `domain.task` 点号）

- 命名空间 = 业务域（`inbox`/`summary`/`consult`/`report`/`documents`/`orchestrate`/`career`/`papers`/`affairs`/`retrieval`）

## 2. Evidence 证据链契约（冻结字段名）

```
Evidence {
  source_document_id: int        # 必填；NULL = 无来源
  chunk_id: int | null
  page: int | null
  confidence: float              # 0.0-1.0
}
```

- 无来源（source_document_id 为 NULL）的行/回答一律标 **【待补充】**，且不打入 AI 生成正文。
- 前端 CitationChip 与 A2 简历行回跳统一消费本契约。
- 扩展字段（source_title/quote 等）一律**追加**，禁止改名。

## 6. 安全边界（ADR 冻结）

- **CORS**：loopback 任意端口正则 `^https?://(localhost|127\.0\.0\.1)(:\d+)?$`，`allow_credentials=False`。
- **X-Local-Token**：`ENABLE_TOKEN` 默认 False 渐进启用（S0 过渡期）；**S1 前置 True**。前端 token 来源唯一 = `GET /api/config`（启动 init + shared_preferences 缓存）。豁免路径：/api/health /api/config /api/admin/demo-status /api/admin/seed。
- **LLM 超时统一 120s**，重试 3 次（1s/2s/4s 指数退避），配置单一来源 config.py。
- **脱敏**：SENSITIVE_FIELDS 默认 `['score','amount','id_card','phone','gpa','rank']`，传输前打码、打码后落库；演示态对真实敏感字段强制打码。
- **演示隔离**：demo_seeds 追踪表为唯一实现；clear 只删登记行；seed/clear 幂等。

## 7. 未决项裁决（S0 启动前结清）

| 未决项 | 裁决 |
|---|---|
| X-Local-Token 生效时机 | ENABLE_TOKEN 渐进启用，S0 False / S1 True |
| CORS 策略 | loopback 任意端口正则 |
| 简历五段结构 | 个人信息/教育背景/科研经历/荣誉奖项/技能与课外活动（无第六段） |
| 接龙去重唯一键 | UNIQUE(signup_id, name) + 覆盖式更新 |
| 演示态隔离粒度 | demo_seeds 追踪表（正式表标位登记） |
| 档案 record_type 初始集合 | honor/score/internship/activity/skill/paper_meta/ledger/signup_row/certificate |
| 收件箱转档案交互 | confirm 端点加可选 `archive:bool` 参数，为 True 建 pending 档案 |
| evidence 字段名 | source_document_id/chunk_id/page/confidence（本 ADR §2） |
| 长任务并发 | 同步阻塞，不做互斥锁；前端 TaskProgressProvider 单实例去重 |
| LLM_MOCK 默认 | False |
| demo 豁免是否含 wipe 确认门 | 不含（clear 已按 demo_seeds 安全回删） |
| rerank 默认阈值 | 候选 >5 条触发 LLM 精排，否则按原序 |
| 综述段落无来源 | 强制标【待补充】，不静默引用 |
| 双栏 PDF 重组 | P1 加分项，P0 以文字版 PDF 兜底 |
| 预录视频 | **不做**（用户决策 4），S5 交付不列此兜底 |
